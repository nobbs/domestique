# Security policy

## Supported versions

Domestique has not made a production release yet. Security fixes are made on
`main` until a release support policy exists.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include credentials,
tokens, route data, or a working exploit in a public discussion.

Before the first release, the maintainer must enable GitHub private vulnerability
reporting for this repository. Use that private reporting form once it is
available. Until then, report only through a private channel already established
with the maintainer; do not disclose the issue publicly.

A useful report includes the affected revision, a minimal reproduction, impact,
and any suggested remediation. The maintainer will acknowledge a report,
confirm its impact, and agree a disclosure timeline privately.
